# Tarea 1 - Escape de la Torre

## Integrantes

- Matías Concha

## Requisitos previos

- Python 3.10 o superior.
- Git instalado para clonar el repositorio.

El proyecto utiliza módulos de la biblioteca estándar de Python, por lo que no requiere instalar dependencias externas.

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
cd Tarea1-IA
```

### 2. Ejecutar el programa

Para ejecutar la simulación principal:

```bash
python main.py
```

### 3. Ejecutar el benchmark

Para ejecutar las pruebas de benchmarking:

```bash
python benchmark.py
```

Al finalizar, los resultados se guardan en:

```text
benchmark_resultados.csv
```

## Consideraciones de ejecución

- Los archivos deben mantenerse dentro de la estructura original del repositorio.
- `main.py` debe ejecutarse desde la carpeta raíz del proyecto.
- `benchmark.py` debe ejecutarse desde la carpeta raíz del proyecto.
- Los parámetros generales de la simulación pueden revisarse en `config.py`.
